# Vekha — от задачи к результату

Интерфейс трекера задач и проектов для продуктовых команд: очереди, доски,
спринты, воркфлоу, автоматизации и отчёты. Фронтенд собран по дизайн-системе
Vekha v2 — двенадцать экранов, светлая и тёмная темы, drag-and-drop и полностью
интерактивные состояния.

## Что внутри

| Экран | Маршрут | Что умеет |
| --- | --- | --- |
| Главная | `/` | KPI-плитки, лента «требует внимания» с фильтрами, мои задачи, активные проекты, сводка спринта, упоминания, активность |
| Задачи | `/tasks` | Таблица с сортировкой по девяти колонкам, переключаемые колонки, изменение ширины столбца мышью, быстрый поиск, чипы-фильтры, множественный выбор и массовые действия, skeleton-загрузка, пустое состояние, пагинация |
| Задача | `/tasks/:key` | Описание с режимом редактирования, подзадачи с прогрессом, вложения, комментарии, история изменений, связанные задачи, панель полей, наблюдатели, смена статуса |
| Доска | `/board` | Канбан с перетаскиванием карточек между колонками, индикатором места вставки, лимитами WIP и сворачиваемыми колонками |
| Спринты | `/backlog` | Планирование спринта: перетаскивание из бэклога, ёмкость команды, распределение нагрузки по людям, предупреждения о перегрузке |
| Очереди | `/queues` | Список очередей с владельцами, воркфлоу и уровнями доступа |
| Проекты | `/projects` | Карточки проектов с прогрессом, командой и сроками |
| Проект | `/projects/:name` | Обзор с вехами и рисками, список задач, диаграмма Ганта с фазами, зависимостями и линией «сегодня» |
| Фильтры | `/filters` | Конструктор условий с группами И/ИЛИ, язык запросов с подсветкой, сохранённые и командные фильтры |
| Отчёты | `/reports` | Burndown, пропускная способность по неделям, кольцевая диаграмма статусов, нагрузка сотрудников, метрики спринтов, просрочки, библиотека виджетов |
| Команды | `/teams` | Составы команд с ролями и загрузкой |
| Настройки | `/workflow` | Схема статусов и переходов (список и граф), поля задачи, матрица прав по ролям, конструктор автоматизаций, шаблоны задач |

Поверх экранов работают общие механики: командная палитра (`⌘K` / `Ctrl+K`
или `/`), создание задачи по `C`, всплывающие уведомления, выпадающие меню и
модальные окна, переключение светлой и тёмной темы с сохранением выбора.

## Дизайн-система

Все значения вынесены в CSS-переменные и живут в одном месте —
[`src/styles/tokens.css`](src/styles/tokens.css). Ни один компонент не
использует сырые цвета.

- **Поверхности** — четыре уровня: `--bg`, `--workspace`, `--surface`,
  `--raised`, плюс `--surface2` для второстепенных плашек.
- **Цвет** — акцент и пять семантических цветов (`ok`, `warn`, `dang`, `info`,
  `vio`) заданы в OKLCH, поэтому тёмная тема получает ту же насыщенность без
  ручного подбора.
- **Типографика** — IBM Plex Sans для интерфейса и IBM Plex Mono для ключей,
  чисел и дат. Размеры от 10.5 до 22 px.
- **Ритм** — радиусы 4–12 px, высоты элементов управления 26/28/30/32 px,
  высота строки таблицы 36 px.
- **Тени** — четыре уровня от `--sh1` (карточка) до `--sh4` (модальное окно).
- **Движение** — восемь именованных анимаций (`vk-pop`, `vk-modal`, `vk-toast`,
  `vk-shimmer`, `vk-grow` и другие), длительности 120–560 мс. При включённом
  `prefers-reduced-motion` анимации отключаются.

Тёмная тема переопределяет только значения переменных — разметка и компоненты
у обеих тем общие.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Приложение поднимется на `http://localhost:5173`.

Сборка продакшен-бандла:

```bash
npm run build
```

Проверка типов без сборки:

```bash
npm run typecheck
```

## Данные

Приложение работает на демонстрационном наборе данных и не обращается к
серверу. Вся доменная модель описана в `src/data`, поэтому подключение
реального API сводится к замене этих модулей на запросы — компоненты получают
данные только через них и через контексты в `src/store`.

Демо-пространство: организация «Норд Софт», шесть очередей (VEKHA, MOB, LMS,
SEC, INT, REL), шесть проектов, шесть участников, 16 задач с ключами,
оценками в story points и сроками.

## Доступность

- Все интерактивные элементы — настоящие `button`, `input` и `textarea`
  с видимым фокусным кольцом.
- Чекбоксы и переключатели снабжены `role`, `aria-checked` и `aria-label`.
- Вкладки используют `role="tab"` и `aria-selected`, модальные окна —
  `role="dialog"` и `aria-modal`.
- Диаграммы помечены `role="img"` с описанием.
- Уведомления объявляются через `aria-live`.
